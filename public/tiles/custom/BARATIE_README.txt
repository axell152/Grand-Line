BARATIE - TILESET
=================

baratie_tileset_32.png : atlas 16x8, cases de 32x32.
baratie_building.png   : façade du restaurant, utilisée comme élément décoratif.

Frames principaux de l'atlas :
0-3   : pont bois
28-51 : bords / coins / transitions
52-73 : coque
74-79 : escaliers
80-95 : bois / portes / détails
96-99 : pierres / lanternes
100-117 : quais / eau / accès

La map du Baratie utilise désormais un terrain en forme de navire,
avec pont, bords, accès latéraux, restaurant central et décorations.
